# Chhoto URL deployment, 9 October 2026

Live native service at https://links.utilibre.org through private port 3208. Chhoto URL 7.8.3-p3, MIT, upstream SinTan1729/chhoto-url commit `e18a8a0111e94be03145e95c30dcd7f41891633d`. Native Rust/Actix application and SQLite, with no new shortening backend. The small reversible patch prevents hit-counter enqueueing and per-click debug logging, hides unused count fields, packages three assets locally and adds factual instance/contact/source navigation. Do not treat hidden count fields alone as the privacy fix; the redirect handler no longer records clicks. Native regression assertions verify zero counts.

Anonymous native creation is enabled, with a maximum 30-day lifetime; a visitor may select a shorter expiry. The app checks expiry on resolution and performs native cleanup hourly. No anonymous link library, account or deletion token exists. Native administrator authentication protects listing, editing and deletion. Keep the original URL and resulting short link; ask through the private contact route for early removal. Possession of a short link reveals its destination. Full submitted URLs, including query strings, fragments and optional notes, are readable by the operator. Do not shorten passwords, decryption links or other confidential capabilities.

The application redirects the visitor; it does not fetch the destination. Destination sites receive the visitor's request after a redirect. Temporary307 redirects avoid a promised permanent browser redirect. Cleaning a URL is a separate task. HTTPS goes through Cloudflare and Caddy; neither the shortener nor a noindex header makes a link confidential. The UI is upstream English; portal instructions use EN/ES voseo.

Native browser sessionStorage caches configuration/login UI state. The administrator cookie is marked Secure, HttpOnly and SameSite=Strict by the gateway. Authentication uses a private Argon2id password hash. No visitor statistics or external assets are loaded. Application/container logging is disabled; gateway access logging is off and error logs rotate at two 5 MiB files. Edge, security/system and provider retention remain independently unverified.

The new app runs on an internal network with no Internet route and no published app port. Gateway private binding3208; application1 CPU/256 MiB, gateway0.25 CPU/64 MiB, read-only root filesystems, dropped capabilities and process caps. Native anonymous creation is limited to2 requests/minute with burst4; login5/minute with burst4; request bodies8 KiB. These are request ceilings, not promised capacity or per-user ownership. Native batched requests remain bounded by the body limit.

Daily04:50UTC plus up to5minutes, `backup.py` uses the native SQLite online backup API and checks integrity, then copies private configuration with operator-only permissions. No automatic expiry; backups remain on this VM and can retain expired/deleted URLs. Native hourly backup copies are disabled because this explicit daily snapshot replaces them. No pre-existing service retention was shortened. Backups are not offsite protection.

Verification:22 native Rust tests passed before the release build. Public HTTPS browser checks passed anonymous creation,30-day cap, anonymous listing/deletion denial, exact307 redirect, native Argon2 login with secure cookie, zero hits after resolution,390px layout and no outside assets/page errors. A network-none container reopened the matching snapshot and returned the exact fictional redirect; checksum, SQLite integrity and the owned row/count matched. Native Shorten button/clipboard and exact-fixture deletion are recorded separately in `chhoto-ui.log`. A generic Python public HTTP client receives Cloudflare1010; ordinary browser use passes. Public programmatic API compatibility is not promised.

Reproduction: `deployment/chhoto/build.py` starts from the pinned clean source, applies the patch, verifies vendored asset hashes and builds the image using the locked Rust dependencies. Dockerfile runs native tests before release compilation. Runtime secrets are under `/opt/utilibre/chhoto-private`, never in the source offer. Source archive: https://tools.utilibre.org/utilibre-source/chhoto-utilibre.tar.gz. Restore the matching image and SQLite snapshot before starting, keep the operator credentials private, and verify the owned test link in isolation. Scope any rollback to this compose project. Remove the adaptation when upstream supports disabling collection and local assets natively.

Dependency check: OSV queried all258 crates.io packages in the pinned lock on9October. One advisory applies to h2 0.3.27: [RUSTSEC-2026-0258](https://rustsec.org/advisories/RUSTSEC-2026-0258.html), unbounded empty HTTP/2 DATA frames. Only the gateway reaches this internal app and it speaks HTTP/1.0 upstream; the app has no published listener or TLS/HTTP2 ingress. That deployed boundary excludes the affected public protocol path. This is a recorded dependency exception, not a clean audit or a claim that the library is fixed. Reassess upstream compatible fixes before allowing HTTP/2 to the app.
