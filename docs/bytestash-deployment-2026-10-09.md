# ByteStash deployment — 9 October 2026

ByteStash 1.5.14-p1 is live at `https://snippets-library.utilibre.org`, backed by `10.10.1.43:3204`. Upstream commit `72adce8872414e4a11ea193d4374309f72b3990c`; image digest and ceilings are pinned in `deployment/community/compose.bytestash.yaml`. The [1.5.14 release](https://github.com/jordan-dalby/ByteStash/releases/tag/v1.5.14) fixes the published snippet-authorization issue. Root licence is GNU GPLv3; only/or-later precision remains unconfirmed, so do not invent an SPDX suffix. It is a searchable multi-fragment snippet library; Opengist separately supplies Git history and HTTP Git.

The native OIDC integration uses existing approved, verified Utilibre accounts. Local accounts and anonymous writing are disabled. Only the existing operator username `akadmin` is designated administrator; the synthetic first OIDC account was not admin. Snippets start private, may be published, and may have unlisted sharing links with expiry and optional authentication. The authentication option admits any valid local account with the link, not a hand-picked recipient list. Server-side SQLite holds plaintext snippets, filenames, categories, settings, account identifiers, native API credentials and access timestamps. It is not end-to-end encryption. Ordinary records have no automatic expiry; recycle-bin entries expire after 30 days through native cleanup. Sharing-link expiry is independent. Browser login state/preferences persist; downloaded JSON/Markdown copies remain until deleted.

Small source changes: OIDC JWT handoff uses a consumed fragment rather than a request query; authorization state is additionally bound to a five-minute secure HttpOnly SameSite cookie; the native JavaScript-readable auth cookie now has Secure. The auth token remains in native localStorage/cookie, with eight-hour server validity. Monaco uses its bundled module instead of an external CDN; the opt-in changelog reads a pinned local public-release snapshot. CSP prevents remote Markdown images and arbitrary external URL imports. Native local file import works. No visitor analytics, remote avatars or background external-browser requests were added. The runtime can contact Utilibre identity; the public Cloudflare/edge path processes HTTP connection metadata under the common deployment notes.

App: 1 CPU, 512 MiB, 128 PIDs; gateway: 0.25 CPU, 64 MiB. Request body cap 10 MB, with native/gateway parsing limits also applying. This is not an account quota. No access logging at the private gateway; warnings/errors and application operation logs use Docker rotation 2 × 5 MB per container, not a fixed retention in days. Logs may identify operations/items; edge/provider retention is separately unresolved.

## Native export, deletion and recovery

Open Settings → Export Snippets (JSON). The JSON contains active snippet titles, descriptions, categories, fragments/code and metadata. Import Snippets accepts this format and creates new copies. It does not restore identity, API keys, sharing links, preferences or original identifiers; recycled snippets are not included in the active-list export. Markdown export produces human-readable code files, not a complete account backup. Keep private exported code private.

Move snippets to Recycle Bin and permanently delete there, or restore before the native expiry. Revoke sharing links and API keys separately when relevant; recipients may retain copies. Native administrator deletion removes the account and dependent records. There is no verified self-service account-deletion control, so use the private operator contact.

Real public HTTPS OIDC, non-admin first signup, local-signup denial, anonymous private-content denial, create/edit/recycle/restore, public and authenticated sharing, and share revocation passed. Native browser JSON export/import reproduced exact fictional code. A stopped-app consistent snapshot was reopened under `--network none`; the native API returned both original/imported copies with exact code bytes. Native admin repository deletion then removed only the exact synthetic account and its two fixtures. The shared synthetic Authentik identity was disabled again and credentials revoked after all agents finished.

`bytestash-backup.py` captures data and private config while stopping only this backend; `utilibre-community-backup.timer` includes it in daily serial snapshots. Backups are same-VM copies without configured automatic expiry. `check-bytestash-restore.py` explicitly targets the fictional fixture snapshot, not the post-cleanup copy. Preserve `.jwt_secret`, SQLite and private OIDC settings when recovering; test into an empty isolated directory first. No offsite recovery is claimed.
