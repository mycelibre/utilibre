# TiddlyWiki single-file deployment, 9 October 2026

TiddlyWiki 5.4.1, commit `d391595836e2aead565480763f9bf9eb52e29e75`, Utilibre p1. [Upstream's latest stable release](https://github.com/TiddlyWiki/TiddlyWiki5/releases/tag/v5.4.1), published 10 July 2026, fixes regressions from 5.4.0. The actual licence text is BSD-3-Clause despite the package's shorter `BSD` label. The public advisory endpoint returned no advisories on 9 October; this is not proof of complete security. The native runtime has no external npm dependencies. No npm install, third-party plugin repository or server listener is used for this build.

Public download entry: `https://tools.utilibre.org/apps/tiddlywiki/`; Spanish: `/apps/tiddlywiki/es/`. Download buttons deliver `tiddlywiki-en.html.download` and `tiddlywiki-es.html.download` as octet streams with `.html` download filenames. The locally opened file is the application and notebook. This boundary avoids running arbitrary imported wiki content under the shared tools origin. No account, database, Node server, remote synchronization, new container or public port is added. Runtime processing occurs in the user's browser; existing static-server limits remain unchanged.

## Native configuration and data scope

`deployment/tiddlywiki/edition` is a supported native edition: the standard vanilla/snowwhite themes, upstream Spanish language pack, an opening Utilibre note and a native RawMarkup head tiddler. The latter adds noindex, no-referrer and an in-file CSP permitting the bundled inline code/styles while blocking external connections, remote images, plugin libraries and embedded remote frames. TiddlyWiki's native module loader needs `unsafe-eval`; this does not enable network access. The native blank editor iframe works under the tested policy. No vendor source patch, UI injection or custom save backend is added. Upstream Spanish controls retain their native translation; all operator-written guidance uses voseo.

A full HTML save includes the notebook's saved notes, bundled editor/themes/language, and included configuration. It is an independent file, not a keys-only backup. A referenced external URL is not copied into the file. DefaultTiddlers determines the initial open notes, so use the sidebar search to find another saved note after reopening. Plugins or extra file formats require separate verification; no universal migration claim is made.

This edition has no browser-storage autosave plugin. Unsaved content remains in the open page and may be lost on closure. Native optional password-storage settings can use localStorage; therefore the guide does not promise that tab closure clears every preference. Downloads are not encrypted by default. No encryption round trip is claimed here. Deleting a note in the native editor requires another HTML save; older downloaded copies/backups/recipients still retain it. There is no hosted user notebook for Utilibre to erase or restore. Protect local files and keep independent backups.

Only application delivery creates website/provider connection metadata in the tested workflow; no external HTTP request occurred during local editing/saving. Edge/security/provider retention is separately unverified. Deliberately following an external link is separate navigation. Import only trusted wiki notes and plugins, which can contain executable code; a restrictive network policy is not a claim that untrusted content is safe.

## Verification and recovery

`python3 deployment/tiddlywiki/build.py` checks the immutable Git pin and clean upstream tree, loads the local edition plus its language setting, and invokes the native `$:/core/save/all` renderer. It uses at most a 768 MiB Node heap, with no package-manager or container build. `build.json` records per-artifact SHA-256 hashes. Upstream licence and embedded third-party notices are preserved. Repeating the build yields the same file hashes.

`node deployment/tiddlywiki/check.mjs URL` downloads the actual application, uses native +/confirm/save controls, reopens a fictional note in a fresh browser context, deletes it through native controls, saves again and confirms absence after another reopen. EN desktop and ES 390px touch layouts, native language selection, no horizontal overflow, and absence of external HTTP requests passed. Phone operating-system file handoff is not proved by viewport emulation. Localized no-JS entry pages remain usable as downloads. Evidence and synthetic HTML fixtures: `/opt/utilibre/reports/single-file-20261009/`.

Publish the built static directory atomically at `/opt/utilibre/toolbox-public/apps/tiddlywiki`; retain any previous static directory for rollback. No user data or backup retention changes. The source offer `https://tools.utilibre.org/utilibre-source/tiddlywiki-utilibre.tar.gz` contains the pinned source, original legal notices and the precise native edition/build/check/landing files. This package is a configurable edition, not a forked notebook service.
