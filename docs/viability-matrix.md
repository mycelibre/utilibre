# Milestone 1 viability matrix

Review date: 2026-08-30

This review uses the canonical upstream repositories, release material, and deployment documentation current on the review date. The decisions are intentionally conservative: a maintained project is not automatically suitable for a small public instance.

Resource figures marked **planning estimate** are sizing envelopes inferred from the documented architecture and the limits selected in `compose.yaml`; they are not presented as measurements. Invidious figures are from its official public-instance planning guidance. Runtime measurements for the services actually started belong in `resource-usage.md`.

## Decision rationale

The deploy set deliberately favors three server-side functions that add clear value:

- Cobalt provides media resolution/streaming that cannot be reproduced meaningfully by a purely local browser tool.
- SearXNG provides a general privacy-preserving search frontend with a supported public limiter and both required interface languages.
- Redlib provides a lean public Reddit frontend after an explicit operator
  decision to accept its Android OAuth/client and TLS/browser-emulation
  workaround. It is useful but English-only and operationally conditional.

That Redlib decision is a narrow policy exception, not a quiet weakening of the
general review rule. Invidious is maintained and bilingual but exceeds the
intended operational and bandwidth envelope. rimgo is small, maintained, and
passed a private compatibility test, but its reviewed `/search` rewrite can
create an arbitrary external redirect; it also lacks a built-in limiter,
proxies potentially heavy media, and has an English-only interface. It
therefore remains an optional disabled profile rather than a launch service.
