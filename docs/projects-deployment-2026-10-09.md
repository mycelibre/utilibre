## Changes and limits

[Deployment recipe](../deployment/projects/README.md) uses the existing reviewed dependency patch plus one readable native React source change: replace unrelated ProConnect branding with Continue with Utilibre / Continuá con Utilibre while retaining the native OIDC handler. The frontend is built normally from pinned source, in a2CPU/4GiB container with2GiB temporary workspace and task-specific npm cache. No compiled vendor-bundle wording patch is deployed. Current image: `sha256:03854cd788d29d27484d825ff69e92e778abd97a2e9328f9dd99f8959f3bfc15`; original pilot image retained.

Native Authentik integration has a strict callback, minimal signed profile/email claims, the existing approved-group and verified-email policies, and no role mapping that grants newcomers administration. The native default administrator email was matched privately to the existing active operator identity; no real account was changed or contacted. `OIDC_IGNORE_USERNAME=true` avoids the native16-character username restriction while retaining issuer/subject/email identity. `OIDC_ENFORCED=true` blocks password sign-in. `ALLOW_ALL_TO_CREATE_PROJECTS=true` permits approved users to create their own boards.

PostgreSQL contains server-readable accounts, project/board/card/task/comment/activity data, memberships, notifications and sessions. Sessions include IP and user-agent metadata. Uploaded attachments, backgrounds and avatars are separate files. Browser cookies, OIDC state and preferences can survive closing the tab. There is no configured automatic expiry for ordinary content or archive rows. No visitor analytics, external widgets, SMTP, S3 or webhooks are enabled. Native supported feedback configuration exposes the bilingual Utilibre return link. External Markdown images and frames are blocked by CSP; only the existing identity edge is allowed for application internet egress.

Native CSV download includes list/card names, descriptions, assignee/label names, due date, completion and completed/total task counts. It omits task text, comments/history, attachment bytes, permissions and account settings. There is no CSV-to-board import. Spreadsheet formulas are not neutralized by native CSV quoting; open untrusted cells as text. Some native Spanish strings, board controls and CSV headings remain English. Operator-authored notes/guides use equivalent English and Spanish voseo.

Explicit attachment deletion removes its active file and archives related metadata. Project deletion makes the project unavailable, archives records and can leave associated files; it is not a full file purge. Native administrator account deletion removes identity links/memberships, sets deletedAt and retains identity fields. Earlier backups and members' separate copies are independent. No historical record purge was introduced.
