The native cleaner removes known tracking parameters and optional explicit removal rules. Unknown/functional parameters, duplicate query values, raw query encoding and fragments are preserved. Keep rules override remove rules. This is deliberate conservative behavior, not a promise that every identifier is recognized. Review each cleaned URL; cleaning does not inspect its destination or establish safety. The application never contacts pasted destinations. The browser fetches the application's own assets; normal hosting connection metadata is a separate matter.

Input/results remain in page memory; the application writes no browser history, localStorage, IndexedDB, cookies or service worker. Reload clears the current inputs/results. Native downloaded rule profiles and reports remain on the user's device. A redacted report hides credentials, query values and fragments but retains domains and paths, which can themselves be sensitive. Redaction is optional: users must protect unredacted reports. Shared tools-origin browser storage belongs to other tools; this app neither reads nor clears it.
