# ChartDB deployment — 2026-10-09

URL: https://tools.utilibre.org/apps/chartdb/ . Upstream 1.20.1, commit `c24936a402bb3e24b4858f05282d69a04fcfe25b`, Utilibre p1. GNU AGPLv3 project grant; only/or-later scope remains unconfirmed rather than guessed. Corresponding source: https://tools.utilibre.org/utilibre-source/chartdb-utilibre.tar.gz . Served by existing tools Nginx, no extra application backend or public port.

ChartDB supplements drawDB with its native database-metadata import/query instructions, visual designer, templates and DBML. Native fictional SQL DDL import, PostgreSQL SQL export/copy, and JSON diagram export/reimport are verified. It does not connect to databases: run any native metadata query yourself on a database you control, inspect the result, and paste only what you intend to work with. SQL definitions/diagram metadata may contain sensitive names/comments; they are processed in this browser, not uploaded by the tested workflow.

Native IndexedDB `ChartDB` stores diagrams. Generic settings/language/workspace-ID/cache keys are namespaced `chartdb.*` to avoid other tools' state. Diagram IDs need a local workspace prefix; it is not sent for visitor analytics. Closing the tab does not delete diagrams. Tools share the same origin; clearing all site data affects other apps too. Native Backup → Export Diagram produces JSON with tables, relationships, dependencies, areas, custom types and notes for a compatible ChartDB import; it is not a backup of database rows or credentials. Downloaded JSON is not automatically encrypted. Use native deletion for selected diagrams and retain independent copies.

## Privacy/build integration

Native DISABLE_ANALYTICS and HIDE_CHARTDB_CLOUD are set. The Fathom loader is removed from HTML, and remote GitHub star iframes become ordinary Utilibre/source links. Raleway fonts, Monaco and its workers are local. Native hash routing and relative assets support the existing path without a second Caddy host. Strict CSP rejects outside scripts, connections, frames and fonts. No AI API key/endpoint/model is configured. Same-dialect SQL generation remains native; AI-assisted cross-dialect conversion is unavailable and must not be promised. Upstream help/community links are explicit outbound navigation.

Monaco 0.57.0 is bundled with a resolver override for DOMPurify 3.4.16; the built editor was checked for 3.4.16. Compatible dependency fixes are recorded in the lockfile. The production audit still reports thirteen findings in unused AI networking packages and build CSS tooling; no AI/network backend, CSS compiler or Node HTTP client is deployed as a service. These are not reported as a clean audit. Monitor upstream removals/updates and reassess before enabling any such feature. No indiscriminate major framework upgrade was made solely to clear a count.

`npm run lint` and TypeScript build passed. Production bundling required a bounded 6 GiB heap (3 GiB was insufficient for the large template/Monaco graph); static artifact about 85 MiB. Runtime CPU/memory for schema editing is the visitor's browser, not a persistent server process. Large imports remain device-dependent.
