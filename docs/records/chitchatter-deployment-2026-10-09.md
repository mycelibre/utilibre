Live at `https://chat.utilibre.org/` through private gateway `10.10.1.43:3200`. The public two-peer text/file/generated-microphone check passed on 2026-10-09. Original upstream `jeremyckahn/chitchatter` commit `23b62a8d95be003e490e5a050335e1dea4b79cc7` (package 0.0.0, version by commit, Utilibre p1), GPL-2.0-or-later per package grant. Source `/opt/utilibre/src/chitchatter`; source offer `/utilibre-source/chitchatter-utilibre.tar.gz` on tools host. Native tracker `bittorrent-tracker` 11.2.3, MIT, pinned lock. This installs the existing applications with configuration glue, not a new chat/authentication backend.

Use the generated UUID room name. Public-room links grant entry to anyone holding/guessing the name and backfill recent messages from peers. Native private rooms additionally require the agreed password; mismatched passwords appear as inability to connect, not a central login error. Peers see one another's IP addresses. Calls/files use direct encrypted WebRTC; no TURN relay is enabled, and restrictive networks may fail. Utilibre's existing `turn.utilibre.org:3478` is used for STUN only; Galene's TURN credentials/peer allowlist remain untouched. Own WebSocket discovery endpoint `/tracker`; no public third-party tracker fallback. Hash routing keeps room names out of ordinary page requests, but discovery hashes, peer identifiers, offers and connection addresses are distinct metadata. Do not describe discovery as metadata-free.

Messages are application-memory state, at most the native 150-message transcript and 10,000 characters per message. Recipients can retain copies. Identity keys/preferences remain in the browser's `chitchatter` localforage database; there is no server account/recovery copy. File transfer uses its native memory store rather than IndexedDB: the package's private-browser detector is replaced with a constant storage choice, without fingerprinting. Large transfers depend on browser RAM and require both peers online. Downloaded files remain on the recipient's device. Native local StreamSaver worker is confined to `/streamsaver/`, not GitHub. Do not claim every file size or every browser is supported.

## Bounded deployment and retention

`deployment/chitchatter/compose.yaml` runs only the native tracker and a static Nginx gateway. Tracker has an internal-only Docker network, no public port or outbound route, 192 MiB/0.5 CPU/32 PID ceilings; Nginx has 64 MiB/0.25 CPU/32 PID ceilings and the private VM port. Read-only filesystems, dropped capabilities, no-new-privileges; no persistent server volumes. No HTTP/UDP tracker or statistics endpoint. WebSocket origins are restricted to the intended public origin and two local verification origins. Native maximum frame is 64 KiB; global discovery sockets 128, 256 discovery hashes and 128 peer entries/hash. Nginx permits 24 tracker connections per forwarded IP and 5 new requests/second with burst20. Those are deployment ceilings, not a measured simultaneous-room capacity promise.

Tracker peers use the native two-minute cache age; a 30-second maintenance pass triggers its lazy expiration and removes empty discovery labels. Disconnect cleanup also removes peers. Active announces refresh membership. Restart clears all tracker memory, and there is no tracker-state backup. Native metadata-bearing tracker logs and Docker logs are disabled; Nginx access logs are disabled and only critical errors are emitted. This does not establish edge, kernel, CrowdSec, STUN or hosting-provider retention; use their separate verified notes. App files may be cached locally. No analytics or message archive was added.
