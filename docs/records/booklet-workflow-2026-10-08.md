BentoPDF already covers basic folded-booklet imposition. No new application or container is needed for that task. A separate Bookbinder JS installation would add advanced binding controls; it would not fill an absent basic-booklet function.

## Verified digital outputs

The deterministic public example `portal/public/examples/booklet-eight-pages.pdf` has eight fictional numbered portrait pages, with TOP/LEFT markers and no embedded scripts, links or personal data. It is generated by the existing `portal/scripts/build-guide-examples.mjs`. `deployment/toolbox/check-booklet.mjs` uses that exact sample through the deployed native interface and reopens every downloaded PDF with PDF.js.

The source modifies page rotation metadata before embedding through `pdf-lib.embedPdf`, but the export path does not transform the embedded content. The preview has its own explicit canvas rotation. Do not infer exported rotation from that preview; the guide uses **No rotation**. No application source mutation was made in this verification task.

The native preview labels four output PDF sides as “4 output sheets”. For the eight-page example these are four PDF pages, representing two physical pieces of paper if successfully printed duplex. The guide explains this distinction. Physical printing, sheet flipping, folding, stitching, printer margins/feed order and large-document memory demand were **not** tested. The native “flip on short edge” instruction is not promoted as universal printer behavior.

The downloaded filename is the original input filename, so the guide asks users to save under a new name. The source fixture's SHA-256 was unchanged after every check. The page count was already divisible by four; blank-page padding for other lengths was read in source but is not claimed as a tested result.

## Network and retention scope

Each of five fresh browser contexts loaded the app from the PDF service, selected the local fixture, generated a preview and downloaded the result. There were 26 requests per English context and 28 for Spanish, all GETs to `pdf.utilibre.org`; no request body, file upload, external request attempt or browser page error was observed. Service workers were blocked for an uncached reproducible check. A browser route guard would abort an outside destination and fail the test; none was attempted. This verifies this native workflow with the fictional sample, not every BentoPDF operation or arbitrary document feature.

The PDF processing happens in the browser. App delivery still uses Utilibre's normal hosting path and produces connection metadata. Original and downloaded files persist on the user's device until deleted; no tab-close deletion promise or output-encryption claim is made. Private test files/results/screenshots are under `/opt/utilibre/reports/booklet-20261008/`; there is no created server record or cleanup token.

## Actual option scope and Bookbinder comparison

BentoPDF provides named US/A/B/C paper sizes, source-rotation choices, 1×2/2×2/2×4/4×4 grids, and auto/portrait/landscape orientation. Only 1×2 uses the folded-booklet order; the other grids use sequential page placement. The UI has no signature-length, binding-margin, sewing-mark, creep or manual-duplex-output controls. Options present in the UI are not all verified: Letter/A4, portrait override, 2×2 and the ineffective clockwise rotation were tested above.

The [official Bookbinder JS interface](https://momijizukamori.github.io/bookbinder-js/) provides standard/custom signatures, perfect-bound output, binding/fore-edge margins, page positioning, custom paper dimensions, fold/cut/sewing/signature marks, flyleaves and specialized zine/small-book layouts. Its [repository](https://github.com/momijizukamori/bookbinder-js) describes a static PDF-Lib-based application. These constitute distinct advanced bookbinding capability. They were inspected in the official documentation/interface, not deployed or functionally tested here. Do not mark Bookbinder fully redundant; prioritize the already-installed workflow for a basic booklet and evaluate the specialized app only for those additional needs.
