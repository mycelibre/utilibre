# rimgo — privately tested, optional, and disabled by default

The maintained canonical project is on Codeberg. Compose pins rimgo 1.4.2 behind the `optional` profile. It has no database and no persistent media volume, but Imgur can block hosting ranges, media relay can consume substantial bandwidth, rimgo has no built-in limiter, and its reviewed interface is English-only. Its reviewed `/search` handler can also rewrite a crafted Imgur-looking query into a protocol-relative external redirect. Public deployment is therefore deferred, no public edge mapping is provided, and the optional profile is for controlled private evaluation only.

On 2026-08-28 this VM successfully loaded the project README's public gallery and served a bounded media range. That is a point-in-time compatibility result, not permission to enable a public instance. Keep `rimgo` out of `ENABLED_SERVICES` and keep `PUBLIC_IMGUR_URL` empty. After an official release fixes the redirect, pin and review that release, provide a maintained edge-side abuse control, set a bandwidth budget, repeat the tests, and accept/document the localization limitation before designing any public route. Do not add a proxy or private credential workaround if Imgur later blocks this VM.
