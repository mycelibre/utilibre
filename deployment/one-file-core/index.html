The One File · Core

Keep an editable diagram in one HTML file.

Download Core

Download, edit, save a new copy

  1. Download the standalone file and open it in your browser. Controls are in English.
  2. Add a node, then choose Save HTML to download your updated diagram. Open the new download to check it. Each save makes another copy.
  3. Browser drafts and recovery history can remain after closing the tab. File encryption is disabled here because upstream saves can retain readable document data. Encrypt the completed file separately with hat.sh if needed. Import only files you trust.

Your documents stay on your device in this workflow. Keep independent backups; this website cannot retrieve or delete your local files. Downloading the application creates normal connection metadata at Utilibre and its hosting providers.
