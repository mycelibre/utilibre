WBO · Utilibre

Temporary shared whiteboards

Draw together without an account. This is a small, experimental service for non-sensitive sketches, not private document storage.

  • Anyone who knows or guesses a board link can read and edit it. There is no end-to-end encryption; Utilibre's server processes the drawing, and Cloudflare handles HTTPS traffic when proxied.
  • Boards are held in server memory-backed storage and are lost when the service stops or restarts. Closing a tab does not delete a board. There is no guaranteed expiry or backup.
  • A board keeps at most 256 drawing objects; older objects are discarded above that limit. Export important work regularly using Download (SVG).
  • Recent board names and preferences can stay in this browser. Avoid sensitive names and clear this site's browser data on shared devices after exporting.
Create an unlisted board

Use it with someone else

  1. Create a board, then copy its complete address to your participant.
  2. Both participants open that address and choose a drawing tool. Allow time for the connected state before drawing.
  3. If disconnected, reopen the same address. If the service restarted, the old drawing cannot be recovered here.
  4. Use Download to save SVG; open the downloaded file to check it. Export is not a promise of editable re-import.

Pizarras compartidas temporales

Dibujá con otras personas sin crear una cuenta. Es un servicio pequeño y experimental para bocetos sin datos sensibles, no un almacén privado de documentos.

  • Cualquiera que conozca o adivine el enlace puede leer y editar. No hay cifrado de extremo a extremo: el servidor de Utilibre procesa el dibujo y Cloudflare maneja HTTPS cuando se usa su proxy.
  • Las pizarras se guardan en almacenamiento de memoria del servidor y se pierden al detener o reiniciar el servicio. Cerrar la pestaña no las borra. No hay plazo de borrado garantizado ni respaldo.
  • Cada pizarra conserva hasta 256 objetos; al superar el límite se descartan los más antiguos. Exportá el trabajo importante con Descargar (SVG).
  • Los nombres de pizarras recientes y las preferencias pueden quedar en el navegador. Evitá nombres sensibles y borrá los datos del sitio en dispositivos compartidos después de exportar.
Crear una pizarra sin listar

Usala con otra persona

  1. Creá una pizarra y compartí su dirección completa.
  2. Abran esa dirección y elijan una herramienta. Esperá a que se conecte antes de dibujar.
  3. Si perdés conexión, reabrí la misma dirección. Si el servicio se reinició, aquí no se puede recuperar el dibujo anterior.
  4. Usá Descargar para guardar SVG y abrí el archivo para comprobarlo. Exportar no garantiza volver a importarlo como proyecto editable.
