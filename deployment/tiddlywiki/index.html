Keep your notes together in a portable HTML notebook.

Download in EnglishDescargar en español

Download, edit, save a new copy

  1. Download an English or Spanish notebook and open the file in your browser.
  2. Create a note, confirm it with the check mark, then use save changes to download the updated HTML. Open that new file and check the note.
  3. This edition has no account or server notebook. Unsaved changes can be lost. Downloads are not encrypted by default. Import only trusted notes and plugins; external resources and remote sync are blocked.

Your documents stay on your device in this workflow. Keep independent backups; this website cannot retrieve or delete your local files. Downloading the application creates normal connection metadata at Utilibre and its hosting providers.
